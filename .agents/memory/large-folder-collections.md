---
name: Large folder collections
description: Expected scale and navigation requirements for the SharePoint and Shufflrr sync folder pickers.
---

Expect very large folder collections in both Shufflrr and SharePoint. Keep folder trees independently scrollable within roughly a screen height, with Save settings accessible at the top.

**Why:** The user expects the folder count in both systems to become very large and does not want to scroll past the trees to save configuration.

**How to apply:** Preserve bounded navigation and visible sync actions when changing the folder-picker layout or loading behavior.
